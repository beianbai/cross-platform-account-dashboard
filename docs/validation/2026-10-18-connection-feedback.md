## 推送后的 CI 修正

首次 Linux / Node 22 CI 中，原有“所有到期平台在未配对时显示离线”的用例失败：固定等待 1.2 秒后，第二个平台仍为 idle。调度器每秒触发，且逐个平台等待持久化，固定延迟不能证明整轮结束。临时加入事件循环延迟后在本机 Node 22 复现相同失败；改为等待两个平台都进入预期状态（最多 5 秒）后，该延迟复现用例通过。仅调整测试等待及记录，不修改业务代码或已安装包。
