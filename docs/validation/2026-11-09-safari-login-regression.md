## 确认的代码问题与修正

1. 0.8.1 删除了旧 `.login-btn` 识别，明确可见的登录按钮不再提示登录。恢复小红书/哔哩哔哩范围内的精确登录动作文字；存在有效本人主页身份时不误判按钮，占位头像链接不算登录身份。修正测试夹具对后代选择器的模拟，避免未覆盖真实层级。
2. 导航只在目标路径检查门槛；小红书回到允许的入口页时继续等原目标，最终报网络超时。现对允许路径均检查登录门槛，仅目标文档可读后结束导航；临时文档卸载会继续等待。
3. 页面脚本执行失败被吞掉。模拟 Safari 拒绝脚本，可重现“小红书网络失败、其余数据识别失败”的组合；这证明错误被掩盖的路径，**不证明用户 Safari 的实际失败就是权限问题**。现区分拒绝读取、脚本错误和检测结果缺失；同时覆盖 Promise 拒绝及 Safari 风格的 InjectionResult.error。
4. 仅传递允许列表中的安全原因码，不传原始脚本错误、账号地址或凭据。原因经扩展、连接服务传到看板，写入平台设置的 lastFailureReason，保留旧账号数据与失败标签页。未登录仍须有页面/路由证据，不能从无法执行脚本推断。

对 Safari 当前网站权限、页面是否实际打开/出现登录框的询问仍待使用者答复；没有把猜测写成实机根因。
