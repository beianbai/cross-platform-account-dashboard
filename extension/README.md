# 跨平台账号看板 · 本地浏览器连接器

这是用户自行加载、只在本机使用的扩展，没有提交浏览器商店，也没有发布到远端。工作台不依赖 Ego Lite；Ego Lite 仍可作为独立可选连接方式。

## 支持范围

- Chrome / Edge 等支持 Manifest V3、scripting 和半分钟 alarms 的现代 Chromium 浏览器：加载 chromium 目录。Chrome 最低 120；Edge 建议使用当前稳定版。其他 Chromium 浏览器须确认允许本地扩展，不能仅因内核相同就保证支持。
- Firefox 115+：加载 firefox 目录的 manifest.json 作为临时附加组件。**未签名，本地临时安装在重启 Firefox 后失效，需要重新加载。** 不声称已完成正式长期分发。
- Safari、移动浏览器以及禁止开发者扩展的受管浏览器：当前没有可用适配器，不会虚假提示“登录即可同步”。不要求改系统默认浏览器；现有缓存仍可浏览。

## Chrome / Edge 首次连接

1. 解压整个连接器包，保留文件夹，不要只移动 manifest.json。
2. 在你自己常用的浏览器打开扩展管理页面：Chrome 为 chrome://extensions，Edge 为 edge://extensions。
3. 自行打开“开发者模式”，点“加载已解压的扩展”，选择 chromium 文件夹。仔细确认扩展权限后安装，不需要安装 Ego Lite。
4. 回 DSH Desktop 的“跨平台账号看板”，选择“常用浏览器 · 扩展连接”，点“生成连接码”。
5. 打开该浏览器工具栏中的“跨平台账号看板 · 浏览器连接”扩展，粘贴连接码，填写便于识别的名称，点“授权连接本机看板”。连接码仅 2 分钟有效、只能使用一次；不要分享。
6. 回工作台选择平台并开始读取。扩展在这个浏览器中新开专用平台标签。如果未登录，亲自在平台完成登录/验证码，再回工作台点“继续读取”。已有登录态直接复用，账号密码不经过工作台。

## Firefox 临时连接

在 about:debugging#/runtime/this-firefox 选择“临时载入附加组件”，选择 firefox/manifest.json，再按上面的 4–6 步操作。扩展在浏览器重启后需要重新加载并按需连接。这是本地开发安装，不是签名商店版。

## 日常使用与恢复

- 一次只授权一个浏览器。重新配对成功后会使旧浏览器凭据失效，不混用不同浏览器账号；切换真实平台账号仍需先解除旧本地账号绑定。
- 连接器保留本机授权，不存平台密码或 Cookie。Desktop 重启通常沿用原端口和授权；如果本机端口被其他程序占用而发生变化，需要重新生成连接码。
- 扩展约每 30 秒轮询本机待办，执行手动同步及用户已开启的平台计划。工作台发出同步到扩展接收通常需要 0–30 秒；浏览器休眠可能更久。也可点扩展里的“检查待执行任务”。
- 完成登录后必须在工作台点“继续读取”；本版不在用户登录过程中持续监视密码框或抢先点击平台。
- 自动任务创建不激活的专用标签，成功后关闭；需要登录或验证时保留页面，等待用户继续。网络重试只复用尚未被用户激活或导航的专用标签。
- 扩展断开按钮停止该扩展轮询并清除本地凭据；工作台的“撤销浏览器授权”使连接 token 在服务端失效。同步期间先等待当前任务结束（最长约 3 分钟），再撤销。
- 如出现连接错误，检查 Desktop 是否运行，扩展是否启用，然后重新配对。不要将连接码提交给任何网站。

## 权限与安全边界

扩展仅申请 storage、scripting、alarms，以及 127.0.0.1 和四个平台所需的精确站点权限；不申请 cookies、history、debugger、webRequest 或全站访问权限。不扫描既有标签，不读取其他浏览器配置/密码库，不复制登录态，不执行平台互动。

本机服务只监听 127.0.0.1，校验 Host/Origin，并要求随机授权凭据；网页本身不能调用。工作台主界面接口仍由 DSH 宿主认证保护。授权配置只保存在插件内部 browser-connection.json（0600）；账号数据仍在原 accounts.json，不包含授权密码。不要分享这些本机内部文件。

扩展将当前页昵称、头像、指标和当前已加载作品发送到本机，服务端重新验证平台地址及账号身份后才保存。无法读取不等于零；失败不会覆盖旧数据。所有连接代码包含在本地扩展中，不从服务器接收任意脚本、不下载或执行远程代码。

## 0.4.0 更新

工作台升级不会自动替换已加载的浏览器扩展。下载新包，将文件替换到原来加载的扩展目录，再在扩展管理页点击重新加载；不要通过卸载再装来更新，以免丢失已有本机授权。若原目录不可用，可重新加载新目录并重新配对。

本版修复 B站投稿页跳转到 /upload/video 后被误判失败，新增本人图文/音频分类读取。扩展显示“已提交”表示结果已交给工作台；最终是否通过账号核验并保存，以工作台同步结果为准。
